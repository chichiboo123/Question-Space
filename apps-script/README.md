# Apps Script 백엔드 배포 방법

`Code.gs`는 Question Space가 쓰는 Google Apps Script 웹앱 코드입니다. 이 저장소에서 버전을 관리하고, 실제 배포는 Apps Script 편집기에서 합니다.

## 처음 한 번만: 스크립트 속성 설정
Apps Script 편집기 → **프로젝트 설정(⚙️)** → **스크립트 속성** → **스크립트 속성 추가**

| 속성 | 값 |
|---|---|
| `SPREADSHEET_ID` | 데이터 스프레드시트 ID (주소창의 `/d/`와 `/edit` 사이 문자열) |
| `ADMIN_PASSWORD` | 새 관리자 비밀번호 (예전에 코드에 있던 비밀번호는 쓰지 마세요) |

비밀번호와 스프레드시트 ID는 코드나 GitHub에 올리지 않습니다.

## 시트 구조
`Questions`, `Comments` 시트 모두 **J열**에 작성자 확인용 토큰의 해시가 저장됩니다. 머리글 행의 J열에 `ownerHash`처럼 이름을 적어 두면 알아보기 쉽습니다. 이 열은 API 응답에 포함되지 않습니다.

## 코드 변경 후 배포
1. `Code.gs` 내용을 편집기에 붙여 넣고 저장
2. **배포 → 배포 관리 → (기존 배포) 수정(✏️) → 버전: 새 버전 → 배포**
   - "새 배포"를 만들면 주소가 바뀌니, 꼭 기존 배포를 수정하세요.

## 순서 주의
서버(Apps Script)를 **먼저** 배포한 뒤 웹앱(GitHub Pages)을 배포하세요. 웹앱을 먼저 배포하면 관리자 로그인(`adminlogin`)이 서버에 없어 로그인할 수 없습니다.
